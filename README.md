# Arco & Fio

Landing page de uma marca fictícia de moda sustentável inspirada no violino. Projeto da disciplina de Programação Front End.

**Tema:** Agenda 2030, consumo responsável e moda sustentável (ODS 12)[cite: 8].

## Ideia

O projeto explora a interseção entre a luthieria tradicional e a sustentabilidade, destacando o compromisso com fontes éticas, a recusa de madeiras ameaçadas (como o ébano) e a busca por alternativas ecológicas no universo da música. As fotos exibidas são do violino do autor.

## Tecnologias

HTML5, CSS3, JavaScript e Bootstrap 5.3 (via CDN)[cite: 8].

## Componentes do Bootstrap Usados

Navbar, cards, popovers (anatomia do violino), barra de progresso, acordeão, formulário com validação e modal. A responsividade usa a grade (`container`, `row`, `col-*`)[cite: 8].

## Como rodar

Abra a pasta no VS Code e use a extensão Live Server no `index.html`, ou abra o arquivo direto no navegador[cite: 8].

## Como publicar no GitHub Pages

1. Crie um repositório e envie os arquivos[cite: 8].
2. Em Configurações > Páginas, escolha um ramo `main` e uma pasta `/ (root)`[cite: 8].
3. O link sai em alguns minutos: `https://wagneroliveira-sec.github.io/arco-e-fio/`[cite: 8].
