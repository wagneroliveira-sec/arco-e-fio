# Arco & Fio

Landing page de uma marca fictícia de moda sustentável inspirada no violino. Projeto da disciplina de Programação Front End.

**Tema:** Agenda 2030, consumo responsável e moda sustentável (ODS 12).

## Ideia
A marca transforma cordas e crina de violino que seriam descartadas em acessórios artesanais e se compromete a não usar madeira ameaçada, como o ébano. As fotos são do violino do autor.

## Tecnologias
HTML, CSS, JavaScript e Bootstrap 5.3 (via CDN).

## Componentes do Bootstrap usados
Navbar, carousel, popovers (anatomia do violino), cards, progress bar, accordion, formulário com validação e modal. A responsividade usa o grid (`container`, `row`, `col-*`).

## Como rodar
Abra a pasta no VS Code e use a extensão Live Server no `index.html`, ou abra o arquivo direto no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório e envie os arquivos.
2. Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`.
3. O link sai em alguns minutos: `https://seu-usuario.github.io/nome-do-repositorio/`.
